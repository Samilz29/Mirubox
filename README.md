## 🚀 Sobre el Proyecto

**Mirubox** es una plataforma web Full-Stack diseñada para el seguimiento, descubrimiento y gestión personalizada de series, películas y anime. 

A diferencia de otras plataformas, Mirubox permite explorar catálogos sin mezclar géneros, ofreciendo un entorno centralizado para trackear horas, interactuar con el contenido y organizar visualizaciones.

### ✨ Características Principales
* **Tracking Detallado:** Registra horas de visualización y mantén un diario exacto del contenido consumido.
* **Sistema de Reseñas y Listas:** Escribe opiniones, califica títulos y genera *tierlists* o listas personalizadas.
* **Catálogos Independientes:** Exploración segmentada de cine, series y anime sin solapamiento de contenidos.
* **Sincronización en Tiempo Real:** Integración total con la API de TMDB (The Movie Database) para obtener metadatos precisos e imágenes de alta calidad.
* **Filtros Avanzados:** Motor de búsqueda optimizado con filtrado a medida.
